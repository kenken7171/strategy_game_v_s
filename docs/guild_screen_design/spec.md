## 5. 確定仕様（2026-06-30 ラフ画 `guild_screens.pdf` ＋ ヒアリング反映）

旅団組合（Guild）フェーズを **右タブ＋左コンテンツの 1 画面・4 タブ構成** に作り替える。

### 画面骨格
- **右カラム＝タブナビ**：縦並び 4 タブ `ユニットリスト / スカウト / アイテム / 結婚`。現在タブは下線で示す。
  クリックで**左カラムの中身だけ差し替える**（タブ切替。フェーズ遷移はしない）。
- **左カラム＝アクティブタブの中身**（下記）。

### タブ1：ユニットリスト
- 旅団員を縦リスト表示。1 行 ＝ [ユニット画像] ＋ パラメータ（ステータス）＋ パッシブ ＋ **［詳細］**ボタン。
- ［詳細］→ ユニット詳細オーバーレイを開く。**そのオーバーレイ内から 解雇 / 引退 / 家系図** を行う（per-unit アクションの集約先）。

### タブ2：スカウト
- スカウト候補を縦リスト表示（行レイアウトはユニットリストと同形：画像＋パラメータ＋パッシブ）。
- 各行の ボタンは **［スカウト］**（押すと採用）。**候補が複数並び、選んで採用**する方式（現状の「即 1 名」から候補一覧へ）。
- 各行にコスト表示（想定。要確定＝§6）。

### タブ3：アイテム
- 旅団共有インベントリのアイテムを縦リスト表示。1 行 ＝ [アイテム画像] ＋ パラメータ ＋ **［装備させる］**ボタン。

### タブ4：結婚
- 親枠を 2 つ横並び（各 [ユニット画像] ＋ **［選択］**ボタン）。線で繋いだ**下中央に子枠**＝**「？」表示**（子の予測内容は出さず「？」のまま）。
- 子枠の**下に［確定］ボタン**（押下で婚姻を実行）。

### ヘッダー（既存・全フェーズ共通）との関係
- **今年の行動（出撃/休息）**は既にヘッダーの「次へ」ボタン文言で表示済み（この画面に専用表示は置かない方針）。
- **家系図**はユニット詳細オーバーレイ（タブ1 の［詳細］）から開く。

## 6. 実装前に決めたい残課題

1. **スカウト候補**：候補は何名並べる？／毎ターン更新する？／コストは固定（現状 BuyCost と別系統）か TargetRating 連動か？
2. **アイテム［装備させる］**：押した後の装着先ユニットの選び方（ユニット選択ピッカーを出す等）。
3. **結婚の［確定］**：コスト表示の有無／自然婚姻（好感度 150 でコスト 0）の扱いはこの画面で残すか。
4. **詳細オーバーレイ**：解雇 / 引退 / 家系図 ボタンを追加（既存 UnitDetailOverlay の拡張）。
