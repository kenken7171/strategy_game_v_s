### 最終旅団の内訳

- **職構成**: HeavyInfantry ×5 / Sniper ×3 / Medic ×3 / StandardBearer ×2 / Sorcerer ×1 / Tactician ×1
  （※ IronWallKnight・Scout は世代交代の中で消失）
- **戦力合計**: HP 約 2350 / FA 合計 約 480 / RA 合計 約 520
- **レベル**: ほぼ Lv1（Lv2 は 1 名のみ）＝ 新陳代謝が速く昇級が乗る前に入れ替わる
- **装備**: 全員なし（高ティアで報酬系を選ぶと装備ドロップ予言を取り逃しやすい）

## 主要な発見

1. **完走する**（100 年到達・例外なし）。多シードでも完走を確認。
2. **家計は伸びない**（残高 4〜13 で横ばい）。獲得 337 ≒ 消費 324 で、稼ぎがほぼ全部
   「増員（婚姻＋スカウト）」に消える。**「家計を伸ばす」と「増員投資」は資源（ポイント）が同じで両立しない**。
3. **寿命死ゼロ**。「満員で最古参を除外」方針が寿命到達より先に必ず追い出すため、
   誰も寿命で旅団を去らない（脱落は全部こちらが切ったもの＝除外 37 件）。
4. **家系は 5 世代まで伸びる**。婚姻方針で血統が縦に深まる。
5. **職が偏る／レベルが乗らない**。婚姻のジョブ 50/50 継承で HeavyInfantry に偏り、
   高速な入れ替えで昇級が乗る前に交代する。前衛核（IronWallKnight）が消えるリスクもある。

## 抜けている観点（要検討）

- **目的の競合**: 「家計を伸ばす」を本当に観たいなら増員を抑える方針が必要（下記）。
- **勝敗は観測対象にならない**: 敵ステ 1 では生存自明。意味ある軸は経済・人口動態・家系。
- **除外基準の副作用**: 最古参除外は“看取り（寿命死）”を構造的に消す。
- **装備・Affix 成長**: 高ティア＝報酬系偏重だと装備が育たない（最終旅団は全員素手）。

## 派生案（必要なら再走）

- **経済特化**: 増員は欠員補充のみ＋予言は RewardPoints 優先 → 残高が伸びる軌跡を観測。
- **戦力維持**: 婚姻の職継承で前衛核が消えないよう、除外時に役割（前衛/回復）を保護。
- **複数シード平均**: 単一シードのブレを均して傾向で見る。
