### 成長モデル（今回 復活実装・C# 版の事実）

旧 TS 版に在り C# 移植で落ちていた **レベル成長＋三段階加齢** を `Core/Unit/UnitStatProfile.cs` で復活させ、
`BattleManager`/`BattleResolver` がユニットの戦闘ステを本解決器経由で読むようにした（素の JobStats を直読しない）。

- **レベル成長**: Lv ごと +25%（Lv1=×1.0 / Lv2=×1.25 / Lv3=×1.5）。上表 #8 の Lv2 は ×1.25 が加齢の衰退を一部相殺。
- **三段階加齢**: 修業期（25 歳未満）は全盛期へ向かい線形成長（#1 の 19 歳は ×0.76 で素より弱い）／
  全盛期（25〜45）は素のまま／**衰退期（45 超）は年 3% 減**（#7 の 50 歳・#8 の 60 歳が素より弱い）。
- 0 値の項（多くの BDEF/BUF/HEAL）は 0 のまま（係数で 1 に膨らませない保護）。
- これに装備ボーナス（基礎値×Lv 倍率＋Affix）が加算される。本家計優先プレイは装備を買わないため、差分は Lv×加齢のみ。

## 主要な発見

1. **家計優先で残高 264**（増員＋装備重視は 2）。資源（ポイント）の振り先で結果は正反対＝いいとこ取り不可。
2. **ユニットは育つ／衰える**: レベル成長（+25%/Lv）＋三段階加齢で、若手は修業期に伸び全盛期で素値、
   45 歳超の衰退期で落ちる（上表）。装備があればさらに上乗せ。基本→最終の差がはっきり出る。
3. **方針で“去り方”が変わる**: 家計優先は寿命死 17（看取りが起きる）／増員重視は除外 36・寿命死 0
   （最古参除外が寿命到達を先回り）。
4. 家計優先は戦力フロア 9 を維持するだけなので入団は 8〜9 で安定、家系は伸びない（婚姻なし）。

## 抜けている観点 / 設計示唆

- **衰退期の運用**: 45 歳超で弱るため、最古参（衰退の進んだ者）を入れ替える運用が理にかなう。一方で
  ベテランは Lv が高ければ衰退を相殺できる＝「育てて長く使う」か「若手と回す」かの判断軸が生まれた。
- **除外と装備の相性**: 最古参除外は装備した古参を流出させる。装備を活かすなら除外順に「装備なし優先」等の保護が要る。
- 敵ステ 1 では生存自明ゆえ、意味ある軸は経済・人口動態・成長（Lv＋加齢＋装備）・家系。
