## 方針（旅団長指定）

| 項目 | 設定 |

| 敵ステータス | **全て 1**（戦闘は必ず自動勝利・損耗ゼロ＝難易度を切り離してフローだけ観測） |
| 予言カード | **ティア最高**を選択（レア度 Gold>Silver>Bronze、同率は効果量→種別順） |

- **職構成**: Tactician ×6 / IronWallKnight ×3 / Scout ×2 / HeavyInfantry ×2 / Medic ×1（Sniper・Sorcerer・StandardBearer は不在）

- **レベル**: 全員 Lv1（新陳代謝が速く昇級が乗る前に入れ替わる）
- **装備**: 14 名中 **2 名のみ装備（SwordKnight Lv1・Affix なし）**。購入 19・ドロップ 3・強化 5 を投じたのに最終はほぼ素手

## 主要な発見

1. **完走する**（100 年到達・多シードでも完走）。子供（15 歳未満）を入団・戦闘・上限から正しく除外しても回る。
2. **装備投資がほぼ無駄になる** — 購入 19・ドロップ 3・強化 5（≒95pt 以上を投資）したのに、
   最終旅団は 14 名中 2 名しか装備していない。**「満員で最古参を除外」方針が、装備した古参を真っ先に切る**ため、
   ギアが除外と一緒に流出する。装備育成と高速除外は相性が悪い。
3. **家計は伸びない**（残高 2〜9）。獲得 296 ≒ 消費 294。増員（婚姻＋スカウト 28）＋装備（27 件）で稼ぎを使い切る。
   **「家計を伸ばす」と「増員＋装備投資」はポイントを取り合い両立しない**。
4. **寿命死ゼロ** — 最古参除外が寿命到達より先に必ず追い出すため、誰も寿命で去らない（脱落は全て除外 36 件）。
5. **家系は 3 世代**。婚姻は 7 件で、入団済の未婚ペアが除外で枯れやすく前回（子も上限カウントした版）より浅い。
6. **職が偏り Lv が乗らない** — スカウト 28 の偏りで Tactician 過多、速い入れ替えで全員 Lv1。

## 抜けている観点（要検討）

- **目的の競合**: 「家計を伸ばす」を本当に観たいなら増員・装備を絞る方針が要る（下記派生案）。
- **除外基準の副作用**: 最古参除外は (a) 寿命死（看取り）を消し、(b) 装備した古参を流出させる二重の副作用。
  「装備持ち・Lv 高は除外保護」等のルールが無いと投資が定着しない。
- **勝敗は観測対象にならない**: 敵ステ 1 では生存自明。意味ある軸は経済・人口動態・家系・装備定着率。

## 派生案（必要なら再走）

- **経済特化**: 増員/装備は欠員補充のみ＋予言は RewardPoints 優先 → 残高が伸びる軌跡を観測。
- **装備定着**: 除外順を「Age/MaxAge 最大かつ装備なし・Lv 低」優先にして投資を守る。
- **戦力維持**: 除外時に役割（前衛/回復）と前衛核を保護し、職偏りを抑える。
- **複数シード平均**: 単一シードのブレを均して傾向で見る。
