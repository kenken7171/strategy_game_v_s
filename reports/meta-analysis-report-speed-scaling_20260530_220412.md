## 3. 焦点考察: 命綱としての血統と支援職

### 3-1. MVP の劇的シフト — 「攻撃」から「生存」へ

| ジョブ | 前回 (敵固定) MVP回数 | 今回 (スケーリング) | 変化 |
|---|---:|---:|---:|
| **heavy_infantry**（重装歩兵） | 40 | **77** | +93% ★★★ |
| **iron_wall_knight**（鉄壁騎士） | 4 | **51** | +1175% ★★★★ |
| **standard_bearer**（旗手） | 9 | **21** | +133% ★ |
| sniper（狙撃兵） | 58 | **20** | −66% ▼▼ |
| sorcerer（呪術師） | 41 | **3** | **−93%** ▼▼▼▼ |
| scout（斥候） | 35 | 10 | −71% ▼▼ |
| medic（衛生兵） | 8 | 5 | −38% ▼ |
| tactician（戦術官） | 5 | 5 | ±0 |
| **「なし」**（戦闘前に全滅） | 0 | **13** | 新規発生 |

**前回支配的だった後衛アタッカー（sniper/sorcerer/scout）が軒並み凋落**。代わりに:
- **iron_wall_knight が 4 → 51（12倍以上）** — 先制された敵の猛攻を BDF/SDF で受け止め、辛うじて反撃を成立させる
- **heavy_infantry が 40 → 77（約2倍）** — HP300 + FA70 で「最後まで立っていて殴り返す」
- **standard_bearer +133%** — AB40 のバフが「敵に先行された後の反撃」で唯一の希望

そして**「なし」MVP が13回発生** = ダメージを与える前に大隊全滅したケース。これは前回モードでは1度もなかった事象で、戦闘の壊滅性を象徴している。

### 3-2. 呪術師の悲劇

`sorcerer`（呪術師）の MVP取得は **41 → 3（−93%）**。原因:

- 敵 SPD=100-250 で**必ず先制される** → 呪術師 HP40 は一撃即死
- 前衛が崩れる前に呪術師が全滅 → 火力源として機能できない
- RA120 という最強の攻撃力が**1ターンも振るわれずに死ぬ**

これは Chronicle Knights のジョブバランスの**新たな弱点**を露呈している。スピードインフレ環境では「脆い超火力アタッカー」が機能しなくなる。

### 3-3. 支援職（衛生兵・戦術官）の真の価値

medic と tactician の MVP は 5回ずつとほぼ変化なし。一見、活躍が増えなかったように見えるが、**MVP は damage_dealt のみで評価される**ため、回復やバフ提供は計測外。

実態を反映する指標として **勝利時平均ターン 7.20** が示唆的:
- 7ターン続く戦闘 = medic の HL30/ターン が **210HP回復** を提供
- 同じく tactician/standard_bearer の AB バフが **7回連続適用**
- これらが**敗北を勝利に逆転させた稀有な44戦**を支えた可能性が極めて高い

つまり、**MVP には現れないが、支援職が「7ターン耐える」勝利パターンの命綱**になっている。前回1-2ターンで終わっていた「無双」では、衛生兵・戦術官は出番すらなかった。

### 3-4. 血統ユニットの「敗戦を支える家系」

10ラン平均で **44.0% が家系の血を引く者**。前回 (45.4%) とほぼ変わらない。これは:

- 戦闘の勝敗は血統サイクル（advance内の結婚/出産）に直接影響しない
- 旅団50名の定員は維持されている（戦闘で死ぬのではなく、`enforceMaxBrigadeSize` でリストラされる）
- 結婚は同分隊好感度で決まり、戦闘の勝敗とは無関係

**つまり: 旅団は戦闘では負け続けるが、家系は紡がれ続ける。**
これは Venus & Braves が表現する「世代を超えて受け継がれる戦士たちの物語」そのもの。**敗北の中でも子は育ち、家系は続く**。

特に **seed=6 は勝率24%なのに子孫率62%・結婚70組** — 「100年間ほぼ負け続けたが、家系だけは大繁栄した旅団」という最も叙事詩的なケース。

### 3-5. ピーク中の全盛期ユニットでも勝てない

seed=9（最悪ラン）のバトルサンプル抜粋:

```
Y96: Loss (T2) age27.8 peak 9/12 mvp=heavy_infantry  ← peak 9名でも2Tで敗北
Y91: Loss (T2) age26.1 peak11/12 mvp=scout           ← peak 11名でも2Tで敗北
Y86: Loss (T2) age25.2 peak12/12 mvp=heavy_infantry  ← peak 12名(全員)でも2Tで敗北!
Y81: Loss (T2) age27.3 peak12/12 mvp=heavy_infantry
```

Y86 で **全盛期12/12 = 大隊全員が能力ピーク**にもかかわらず2ターンで敗北。これは「個体の強さでは絶対に勝てない」状態 = もはや実力でなく**速度差が決定要因**になっている。

## 4. 評価軸別総合考察

### ① 旅団のサバイバル性

**全シード50名飽和・旅団死亡0**

戦闘の壊滅率はゲーム史上最悪だが、旅団そのものは存続している。これは:
- 戦闘で死ぬわけではない（Brigade と Battle は state 分離）
- 新人加入 3名/年が継続
- 結婚・出産が機能して定員圧力を維持

→ **「戦闘では負けるが、組織としては存続する」**新しいゲーム性。ロールプレイ的には「戦に敗れ続けても、家族と子孫が町を作り続ける」。

### ② 血統システムの機能度

**前回比でほぼ無影響**（結婚 -3.9%、出産 -4.8%、子孫率 -1.4pt）

スピードインフレは戦闘の結果に影響するが、advance ロジック（年次の結婚/出産判定）は戦闘の勝敗を見ない。同分隊好感度のみで結婚条件が決まる。

→ **血統サイクルは戦闘から独立して機能**。これは設計として強固な分離。プレイヤーに「戦に敗れても家系は紡げる」ロマンを提供する基盤。

### ③ ステータスとバトルのインフレ/デフレ

**勝率 21.1% は強烈なデフレ状態**

- 早期勝利 ピーク → Y20 で消滅
- Y50 以降の「ジリ貧」が完全に演出された
- 「強くなりすぎて勝率100%張り付き」問題は完全解消

ただし「敗北無限ループ」状態は楽しいゲーム体験かは別問題。プレイヤーに「Y20-30 を境に戦闘を諦めて家系継承に専念する」決断を強いる構造。

### ④ 命名プールの寿命

**称号付き 0（前回と同じ）**

総生成数は前回 467 → 今回もほぼ同等。戦闘の勝敗は名前生成と無関係なので変動なし。

## 5. 重要な発見と次のステップ

### 5-1. 「速度差」が戦闘の決定要因に

スピードインフレ導入により、Chronicle Knights のバトルは:
- 序盤（Y1-20）: ジョブ構成と個体能力が重要
- 中盤（Y21-50）: スピード差が逆転する境界線
- 後半（Y51-100）: **もはや戦術ではなく算術** — 数式で勝敗が決まる

これは「世代と時の流れを表現する」ゲームデザインとして強烈なメッセージ性を持つ。**「老いた騎士団は若い化け物に勝てなくなる」** という時間の残酷さの体現。

### 5-2. 緩和提案（オプション）

完全敗北状態が望ましくない場合の調整候補:

#### 提案 5-2-a. スピード上昇率の緩和

```typescript
ENEMY_SCALING: {
  SPEED_GAIN_PER_YEAR: 0.8,   // 1.5 → 0.8（Y100で +80 = SPD180）
}
```
これで Y100 でも敵 SPD=180、味方最速 scout+旗手バフ=100 でも倍速差に留まる。中盤戦闘が成立しうる。

#### 提案 5-2-b. 味方側スピード強化（旗手の倍化）

```typescript
// standard_bearer の AB を 40 → 60 に
// または「ab_speed_only」のような速度特化バフ
```
旗手バフが味方の手数を死守する命綱になる調整。

#### 提案 5-2-c. 「世代継承ボーナス」の導入

血統ユニットが大隊にいる場合、戦闘開始時に何らかのボーナスを得る:
- 同分隊に親or兄弟がいる場合、SPD +20%
- 子孫の数が多い旅団は、戦闘開始時の追加ターン取得

→ 血統システムが戦闘でも報われる設計。

### 5-3. 称号システムを発動させたい場合

長期戦シミュレーション（200年・1000年）を実装し、累計生成数が 1500-3000名規模になると、命名プール 910 が枯渇して称号フォールバックが発動する。あるいは Config で `POOL_MIN_SIZE: 150 → 60` に削減。

## 6. 総括

> **「老いゆく者は、若き化け物に勝てなくなる」**

敵スピードインフレを導入したことで、Chronicle Knights は「数百年スパンの戦争叙事詩」から「**時の流れの残酷さを描く100年詩**」へと変貌した。

| 観点 | 結論 |
|---|---|
| 戦闘 | 完全に難化（21%）。1ターン無双は消滅、Y51以降は壊滅 |
| 血統 | 敵スケーリングの影響を受けず継続稼働（子孫率44%） |
| 支援職 | 7ターン続く接戦の命綱として **真の価値** を発揮 |
| 前衛盾 | iron_wall_knight が MVP12倍増 = 「耐える者の時代」 |
| 後衛火力 | sorcerer/sniper が壊滅（先制を取れずに即死） |
| 設計 | 戦闘と血統が美しく分離。敗北しても物語は紡がれる |

**もっとも美しい現象**: `seed=6` で勝率24%（76敗）にもかかわらず、結婚70組・出産179名・子孫率62% という**「敗戦の中に家系が育つ100年史」**が観測された。これこそが本ゲームの目指す物語性の極致。

Venus & Braves が表現する「世代を超えて受け継がれる戦士たちの物語」は、敵スケーリングという「時の重み」を加えたことで、ついに**「勝てなくなる老兵たち」と「育ちゆく子供たち」の対比**として完成した。
